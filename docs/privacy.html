Политика конфиденциальности

CalCalc · обновлена 30 октября 2026 г.

Какие данные использует приложение

  • Дневник питания и активности, вес, профиль (пол, год рождения, рост, цель). Хранятся на вашем телефоне.
  • Адрес электронной почты Google-аккаунта. Нужен, чтобы показать, под каким аккаунтом вы вошли, и проверить, что у аккаунта есть доступ к ИИ.
  • Доступ к Google Диску только к файлам, созданным CalCalc (разрешение drive.file). Приложение создаёт одну таблицу «CalCalc» и записывает в неё ваш дневник. Другие файлы на вашем Диске приложение не видит.

Куда передаются данные

  • Таблица хранится на вашем Google Диске и принадлежит вам. Разработчик к ней доступа не имеет.
  • Текст записи о еде (например, «гречка с курицей 300 г») и ваш вес отправляются на сервис распознавания калорий разработчика (Google Apps Script и собственный компьютер разработчика с локальной моделью ИИ). Текст используется для ответа; для поиска ошибок он вместе с адресом почты и временем записывается в служебный журнал разработчика, где хранятся только последние несколько тысяч событий.
  • Друзья и семья (по желанию). Чтобы вас могли найти по e-mail, сервис помнит адреса тех, кто входил в CalCalc. Если вы приняли приглашение или ваше приглашение приняли, приложение отправляет на сервис разработчика вашу еду за последние 30 дней (название, калории, БЖУ, состав, без фото). Её видят только люди, с которыми у вас есть принятая связь. Когда вы убираете последнюю связь, отправленная еда удаляется.
  • Данные не продаются, не используются для рекламы и не передаются третьим лицам.

Использование данных Google

Использование и передача информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Удаление данных

Удалите приложение, чтобы стереть данные на телефоне. Таблицу «CalCalc» можно удалить на своём Google Диске. Отозвать доступ: myaccount.google.com/permissions.
